# Fuentes incluidas

Estas fuentes se incluyen en `GuanacasteStudio.exe` para reproducir la tipografía del prototipo visual.

| Archivo | Fuente | Titular | Licencia |
|---|---|---|---|
| `Inter-Regular.otf`, `Inter-SemiBold.otf` | Inter | The Inter Project Authors (2020) | SIL Open Font License 1.1 — https://openfontlicense.org |
| `JetBrainsMono-Regular.ttf`, `JetBrainsMono-Medium.ttf` | JetBrains Mono | The JetBrains Mono Project Authors (2020) | SIL Open Font License 1.1 — https://openfontlicense.org |
| `MaterialSymbolsOutlined.ttf` | Material Symbols (Outlined, variable font) | Google LLC | Apache License 2.0 (`LICENSE-Material-Symbols.txt`) |

La OFL permite incluir y redistribuir las fuentes con un programa, sin venderlas por separado. Material Icons es de
uso libre con la licencia Apache 2.0. Las fuentes no se han modificado.

Origen de Material Symbols: repositorio oficial https://github.com/google/material-design-icons, archivo `variablefont/MaterialSymbolsOutlined[FILL,GRAD,opsz,wght].ttf` (10.7 MB, descargado el 2026-11-12). Se usa la instancia por defecto de la fuente variable (relleno 0, peso 400); los puntos de código provienen del archivo `.codepoints` del mismo repositorio. El archivo no se ha modificado.
